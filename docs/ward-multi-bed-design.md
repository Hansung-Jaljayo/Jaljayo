# 병상용 설계: 침대 한 대에 보드 한 대, 시연은 보드 한 대에 침대 세 대

## 1. 정한 것

- **제품(상업화 기준):** 침대 한 대에 보드 한 대를 넣는다. 3인실이면 보드도 세 대이고, 보드마다 자기 침대 하나만 맡는다.
- **시연:** 보드가 한 대뿐이라 보드 한 대 안에 "가상 보드" 세 개(사과, 포도, 딸기)를 둔다. 세 개는 서로 섞이지 않고 각자 제품의 보드 한 대처럼 동작한다.
- 시연 화면에서는 101 사과, 102 포도, 103 딸기 침대가 보드 명령대로 따로 움직인다.

## 2. 제품 구조: 침대 한 대 = 보드 한 대

```
[사과 침대 제어부] ── [보드 A: 이름 "사과 침대"] ── 마이크·스피커 A
[포도 침대 제어부] ── [보드 B: 이름 "포도 침대"] ── 마이크·스피커 B
[딸기 침대 제어부] ── [보드 C: 이름 "딸기 침대"] ── 마이크·스피커 C
```

| 보드 한 대가 하는 일 | 내용 |
|---|---|
| 듣기 | 자기 마이크로 늘 듣는다. 병실의 말은 세 보드가 모두 듣는다 |
| 자기 이름에만 반응 | "포도 침대"를 들으면 보드 B만 "네, 포도 침대예요"로 답하고 다음 말을 받는다. 다른 보드는 이름이 달라 무시한다 |
| 자기 침대 상태 | 각도, 목표, 저장 자세, 알람, 예약, 앞 대답([앞 대답]), 압력 센서를 자기 것만 가진다 |
| 자기 침대 제어부 | 제어부 하나와 연결해 `bed-move`/`bed-stop`을 보내고 `bed-state`를 받는다 |
| 대화 모델 | 자기 보드 NPU에서 돌린다 |
| 말하기 | 자기 스피커로 말한다 |

이웃 침대의 소리 처리:

- **이웃 보드의 대답:** "네, 포도 침대예요"를 사과 보드가 들어도 이름이 "포도"라 반응하지 않는다. 다만 이웃 대답 속 명령 같은 말을 명령으로 받지 않도록, 보드 목소리에 사람 귀에는 안 들리는 표시(워터마크)를 넣고 표시가 있는 소리는 무시한다(예정).
- **자기 대답:** 자기 스피커 소리는 에코 제거로 지운다(예정). 에코 제거가 들어가면 지금 쓰는 "대답 직후 몇 초는 자기 목소리로 본다"는 시간 규칙(stripAckEcho, nearAck)은 뺀다.

## 3. 시연 구조: 보드 한 대 안의 가상 보드 세 개

```
                         ┌─ 가상 보드 "사과": 상태·센서·제어부 접속(hello name 사과) ── 시연 화면 101 침대
마이크 → 받아쓰기 → 이름 판정 ┼─ 가상 보드 "포도": 상태·센서·제어부 접속(hello name 포도) ── 시연 화면 102 침대
       (한 번)        (라우터) └─ 가상 보드 "딸기": 상태·센서·제어부 접속(hello name 딸기) ── 시연 화면 103 침대
                 대화 모델 하나 · 스피커 하나(차례대로 말함)
```

### 3.1 제품의 일과 시연의 대응

| 제품: 보드 한 대가 하는 일 | 시연: 보드 한 대 안에서 하는 방식 | 코드 |
|---|---|---|
| 자기 침대 상태 | 침대마다 `BedState`를 따로 둔다. 지금 부른 침대가 `state`, 나머지는 `beds`. 파일도 침대마다 따로 저장(`bed_사과.json` 등) | `BoardService.beds`, `storeFor()` |
| 자기 이름에만 반응 | 마이크와 받아쓰기는 한 번만 하고, 이름 점수(NameScorer)로 부른 침대를 정해 그 가상 보드로만 넘긴다. 병실에 없는 이름은 대답하지 않는다 | `heard()`의 `wardCall`, `switchTo()` |
| 자기 침대 제어부 | 침대마다 이름 붙은 접속 하나(`hello role bed name`)와 `BedLink` 하나. 명령은 그 침대 접속으로만 간다 | `net/WardLinks.kt` |
| 부르지 않은 침대의 움직임 | 예약 실행, 알람 때 상체 올림, 이어지는 움직임이 그 침대 제어부로 간다. 제어부가 붙어 있으면 그 각도를 쓴다 | `tickOtherBeds()`, `WardLinks.step()` |
| 앞 대답([앞 대답]) | 침대를 바꾸면 비운다. 다른 침대에 한 말이 모델 입력에 섞이지 않게 | `switchTo()`의 `prevReply.clear()` |
| 압력 센서 | 침대마다 따로(`sensors["포도"]`). 글에 `bed`가 있으면 그 침대 센서로 받는다 | `sensorOf()` |
| 버튼 | 글에 `bed`가 있으면 그 침대를 부른 것처럼 바꾼 뒤 처리 | `routeBed()` |
| 자기 침대의 폰 | 폰이 `hello`에 `bed`를 붙이면 그 침대 상태만 받고 그 침대만 조작한다. 부른 침대가 바뀌어도 폰은 그대로. 시연 폰은 사과 침대 | `phoneBed`, `onRequest()`, `publishApp()` |
| 알람 | 침대마다 따로 울린다. 부르지 않은 침대의 알람 시각이 되면 그 침대로 바꿔 울린다 | `tickOtherBeds()` |

### 3.2 시연에서만 같이 쓰는 것(제품에서는 침대마다 따로)

| 같이 쓰는 것 | 시연에서 섞이지 않게 한 방법 | 제품 |
|---|---|---|
| 마이크·받아쓰기 | 한 번 받아 쓴 글을 이름 판정으로 한 침대에만 넘긴다 | 보드마다 자기 마이크 |
| 대화 모델 | 모델 입력의 [상태], [앞 질문], [앞 대답]을 그 침대 것만 넣는다 | 보드마다 자기 모델 |
| 스피커 | 말하기 줄(Speaker의 차례 실행기)이 하나라 대답이 겹치지 않고 차례로 나온다. 부르지 않은 침대의 대답은 "포도 침대, 머리를 올렸어요"처럼 이름을 붙인다 | 보드마다 자기 스피커 |
| 듣는 창 | 한 번에 한 침대만 명령을 기다린다(마지막으로 부른 침대) | 보드마다 따로 기다림 |

## 4. 침대 제어부 연결 형식(요약)

자세한 글 모양은 `docs/interfaces/board-link.md`의 "병상용(침대 여러 대)" 절에 있다.

1. 시연 화면이 침대마다 접속을 연다: `{ "type": "hello", "role": "bed", "name": "포도" }`
2. 보드는 그 침대 각도로 바로 맞추라는 `bed-move`(`snap: true`)를 보낸다.
3. 목표가 바뀌면 그 침대 접속으로 `bed-move`/`bed-stop`을 보낸다.
4. 제어부는 0.2초마다, 그리고 끝날 때 `bed-state`를 보낸다. 보드는 접속으로 어느 침대인지 안다.
5. 보드는 `state` 글의 `ward` 배열에 침대마다 각도, 목표, 자세, 물음, 알람, 예약, 저장 자세, 연결 여부(`linked`)를 담는다.
6. `turn`, `speech` 글에는 어느 침대 일인지 `bed`를 붙인다.

`name`이 없는 예전 침대 역할 접속(가정용, 예전 시연 화면)은 지금처럼 부른 침대를 따라간다.

## 5. 고장과 연결 처리

| 상황 | 보드가 하는 일 | 이유 |
|---|---|---|
| 움직이는 중에 그 침대 접속이 끊김 | 마지막으로 받은 각도에서 멈춘 것으로 보고(목표 = 지금 각도), 다시 붙을 때까지 움직이지 않는다. `linked: false` | 실제 침대라면 끊긴 동안 각도를 모른다. 움직이는 척하면 위험하다 |
| 한 번도 붙은 적 없는 침대 | 시뮬레이션으로 각도를 센다(초당 6도) | 제어부 없이 보드만 시험할 때 |
| 같은 이름으로 다시 접속(화면 새로 고침) | 예전 접속을 끊고 새 접속으로 바꾼다. 새 접속에 그 침대 각도로 `snap` | 접속이 둘이 되어 명령이 갈라지지 않게 |
| 병실에 없는 이름으로 접속 | 받지 않고 끊는다 | 엉뚱한 침대 명령 방지 |
| 제어부가 `result: stopped`나 `error` | 멈춘 자리를 새 목표로 받아들인다. `error`는 기록에 남긴다 | 같은 명령을 다시 보내지 않게 |
| 병실 침대 구성이 바뀜 | 새 병실에 없는 침대의 접속은 끊고, 남은 접속은 다시 읽은 각도로 맞춘다 | |

## 6. 동시에 일어나는 일

| 상황 | 동작 |
|---|---|
| 사과가 움직이는 동안 포도를 부름 | 사과는 끝까지 움직이고, 다 가면 "사과 침대, 머리를 올렸어요"를 말한다. 포도는 부른 대로 명령을 받는다 |
| 사과 알람이 울리는 동안 포도를 부름 | 받지 않는다. 울리는 침대 이름만 받는다(11/15 결정) |
| 부르지 않은 침대의 알람 시각 | 그 침대로 바꿔 울린다. 상체 올림을 켠 알람이면 그 침대 제어부로 머리 30도 명령을 보낸다 |
| 두 침대 알람이 같은 시각 | 보드가 하나라 **알람은 하나만 울린다.** 같이 시각이 된 알람 중 **먼저 맞춘 알람(맞춘 때 `setAt`)** 하나만 울리고, 나머지는 울린 것으로 친다. 울리는 동안 다른 침대 알람 시각이 되어도 울리지 않고, 울리던 알람을 끄거나 미루면 그 알람들도 끝난 것으로 친다. 시연 버튼 `alarm-now`도 울리는 중이면 울리지 않는다(시연 한계, 제품에서는 보드가 따로라 겹치지 않음) |
| 부르지 않은 침대의 예약 시각 | 말 없이 그 침대 제어부로 움직인다(받을 때 미리 알려 줌) |
| 대답이 겹침 | 스피커가 하나라 차례로 말한다. 부르지 않은 침대의 대답에는 침대 이름을 붙인다 |
| 침대 버튼(시연 화면) | 그 침대를 부른 것처럼 바꾼 뒤 처리. 다른 침대 알람이 울리는 중이면 받지 않는다 |

## 7. 시연 화면용 시험 글

시연 화면의 「알람 시각이 됨」, 「예약 시각이 됨」 버튼이 보드에 붙어 있을 때 보내는 글이다. 보드가 시연 모드(병실 침대 2대 이상)일 때만 받는다.

- `{ "type": "demo", "action": "alarm-now", "bed": "포도" }`: 포도 침대의 다음 알람 회차를 지금 울린다. 그 회차를 울린 것으로 적어 두어 실제 시각이 와도 두 번 울리지 않는다.
- `{ "type": "demo", "action": "reservation-now", "bed": "사과" }`: 사과 침대 예약 시각을 지금으로 바꾼다. 보드가 시각을 알 때만 실행된다.

## 8. 제품 전 할 일

1. **접속 인증:** 지금은 같은 공유기에 있는 누구나 침대 제어부로 붙어 가짜 각도를 보내거나, 시험 글을 보낼 수 있다. 제품에서는 침대 제어부와 보드를 짝 맺기(등록할 때 받은 열쇠로 인증)하고, 시험 글은 받지 않는다.
2. **에코 제거와 워터마크:** 자기 대답과 이웃 보드 대답을 소리 단계에서 걸러 낸다. 들어가면 시간 규칙(stripAckEcho, nearAck)을 뺀다.
3. **제어부 생존 확인:** 제어부가 `bed-state`를 1초 넘게 안 보내면 끊긴 것으로 본다(지금은 접속이 끊길 때만 안다).
4. **보드끼리 시각 맞추기:** 보드가 여러 대라 알람 시각이 보드마다 어긋나지 않게 같은 시각 출처를 쓴다.
