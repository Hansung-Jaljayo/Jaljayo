# 학습 데이터

## 폴더

| 폴더 | 내용 | 직접 고치나 |
| --- | --- | --- |
| `seed/` | 사람이 쓴 문장과 정답 원본 | 고칩니다 |
| `scripts/` | 원본을 읽어 검사하고 데이터를 만드는 코드 | 코드를 고칠 때만 |
| `datasets/v0.2/` | 코드가 만든 결과 | 고치지 않습니다. 코드를 다시 실행합니다 |
| `sources/` | 외부 자료의 출처, 라이선스, 받는 법 | 자료를 추가할 때 |

## 원본 (`seed/`)

| 파일 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `representative_rows.json` | 기능마다 대표적인 문장 271개와 정답 | 개발용 |
| `real_answers.md` | 상황 질문 60개에 팀원이 답한 원문 | `real_rows.json`의 재료 |
| `real_rows.json` | 위 답변을 표현 하나씩 나누고(274개) 숫자를 한글로, 오타를 고친 뒤 정답을 붙인 것 | 평가용 |
| `motion_samples.json` | 침대 자세 명령 견본 56개와 정답, 출처 | 학습 문장을 늘릴 때의 정답 기준 |

정답은 실제로 말한 칸만 적습니다(`"cmd": "call", "fields": {"purpose": "read"}`). 나머지 칸은 코드가 none으로 채우고 규격 순서대로 완성합니다.

## 만드는 법

`ai/data/scripts/`에서 실행합니다.

| 코드 | 읽는 것 | 만드는 것 |
| --- | --- | --- |
| `build_rep.py` | `representative_rows.json` | `representative.md` (검토표) |
| `build_real.py` | `real_rows.json` | `real.md` (검토표) |
| `samples_motion.py` | `motion_samples.json` | `samples_motion.md` (검토표) |
| `build_train.py` | 코드 안의 낱말 목록, 위 두 원본 | `train.json`, `dev.json`, `final.json`, `split.md` |

모든 코드는 정답이 `ai/spec/spec.py` 규격에 맞는지 먼저 검사하고, 하나라도 틀리면 아무것도 저장하지 않고 멈춥니다.

## 나누는 기준 (`datasets/v0.2/`)

| 파일 | 개수 | 내용 |
| --- | --- | --- |
| `train.json` | 2,249 | 학습용. 낱말 목록을 조합해 만든 문장 |
| `dev.json` | 259 | 개발용. 대표 문장에서 평가용과 겹치는 12개를 뺀 것. 틀린 것을 보고 데이터를 고칠 때 씁니다 |
| `final.json` | 274 | 평가용. 실제 사용자 문장. 점수만 보고 데이터를 고칠 때 쓰지 않습니다 |

- 세 묶음은 서로 겹치지 않습니다. 앞말("야", "음")과 띄어쓰기만 다른 문장도 같은 문장으로 봅니다.
- 평가용 문장은 규격을 정하면서 여러 번 봤으므로 처음 보는 말에 대한 시험은 아닙니다. 그 시험은 새로 모은 문장으로 따로 합니다.

## 알려진 한계

- 학습용 문장이 모두 낱말 목록으로 만든 문장이라 말투가 단조롭습니다. 외부 자료(MASSIVE 등)의 사람 문장을 중심으로 다시 만들 예정입니다.
- 개발용 대표 문장과 학습용 문장을 같은 쪽에서 써서 개발용 점수가 실제보다 높게 나올 수 있습니다.
