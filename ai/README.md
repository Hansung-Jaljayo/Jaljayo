# 온디바이스 AI

사용자 말을 받아 `<maum_0>(command=call, purpose=read)<maum_end>` 같은 명령 출력을 내는 모델을 만듭니다. 기본 모델은 Llama-3.2-1B-Instruct이고, 학습한 모델을 보드(QCS6490)용으로 변환해 보드 앱에서 실행합니다.

## 순서

1. **데이터 준비** (`data/`): 문장과 정답을 만들고 학습용, 개발용, 평가용으로 나눕니다.
2. **학습** (`train/`): GPU에서 학습합니다.
3. **평가** (`eval/`, `experiments/`): 평가 문장으로 채점하고 결과를 실험별로 남깁니다.
4. **변환** (`export/`): 보드용으로 변환하고, 양자화는 마음AI에 요청해 결과를 받아 검증합니다.

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `spec/` | 출력 규격(`spec.py`: 명령, 칸, 허용 값, 학습 문장 뒤에 붙는 함수 설명)과 규격 검사기(`check.py`) |
| `data/` | 학습 데이터. 자세한 내용은 `data/README.md` |
| `train/` | 학습 코드와 설정 (준비 중) |
| `eval/` | 채점 코드 (준비 중) |
| `experiments/` | 실험별 데이터 버전, 설정, 점수 기록 |
| `export/` | 보드용 변환 코드와 양자화 요청 절차 (준비 중) |

출력 규격의 뜻과 근거는 `docs/system-design.md`, 앱이 출력을 처리하는 규칙은 `docs/interfaces/`에 있습니다.
